# 12단계 기억 공간 QA 계획

## 범위

기억 공간과 하얀 방 사이의 왕복 이동, 안전 구역, 첫 퍼즐, 진행 상태 저장·복원을 검증한다. 외부 유료 에셋은 사용하지 않으며, 씬 연출은 프로젝트 내 리소스만 사용한다.

## 자동 회귀 기준

- 기억 공간 식별자가 등록된 상태에서 입장 요청이 성공한다.
- 기억 공간에서 하얀 방으로 탈출하면 현재 위치와 진행 플래그가 저장된다.
- 저장 데이터를 새 런타임에 복원했을 때 마지막 공간과 퍼즐 진행도가 유지된다.
- 안전 구역 안에서는 위험/리셋 이벤트가 플레이어 진행도를 지우지 않는다.
- 퍼즐을 완료하면 동일 퍼즐을 재입장해도 완료 상태가 중복 적용되지 않는다.
- 잘못된 공간 식별자와 손상된 진행 데이터는 안전한 기본 상태로 거부된다.

## 수동 스모크

1. 실행 후 하얀 방에서 기억 공간 입구를 조사한다.
2. 기억 공간에 입장해 안전 구역과 첫 퍼즐을 확인한다.
3. 퍼즐 상호작용 후 하얀 방으로 복귀한다.
4. 다시 입장해 퍼즐 완료와 진행에 따른 하얀 방 변화를 확인한다.
5. 저장/불러오기 후에도 마지막 위치와 해금 상태가 동일한지 확인한다.

## 승인 및 실행

하위 작업은 테스트 코드와 문서만 작성하고 커밋·푸시 또는 승인이 필요한 명령은 실행하지 않는다. Unity EditMode, Windows Development 빌드, 런타임 스모크와 최종 Git 검토는 관리자가 수행하고 승인한다.
