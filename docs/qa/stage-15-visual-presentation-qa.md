# Stage 15 시각 표현 및 화면 사용성 QA

## 목적

사용자 스크린샷에서 확인된 반복 회색 상자, 보이지 않는 첫 목표, 중앙 통로 점유, 낮은 조명 대비와 과도한 영어 일시정지 창이 다시 발생하지 않도록 플레이어 관점의 합격 기준을 고정합니다.

## 자동 계약

- 프롤로그 도착 지점에서 유나까지 거리가 9m 미만이며, 유나는 캡슐 몸체·얼굴·`YUNA` 표지·전용 키 라이트로 구분되어야 합니다.
- 150개 `OpeningStoryAction`은 각각 정확히 하나의 `Stage15StoryActionInteractable`에 연결되어야 합니다.
- 행동 오브젝트 이름은 `Story Action`, 숫자 인덱스 같은 구현 표기를 노출하지 않고 `Character`, `Furniture`, `Doorway`, `Document`, `Clock`, `Terminal` 등 최소 10종 이상의 의미 표현을 사용해야 합니다.
- 기존 `Interaction Gallery Floor`와 장 완료를 우회하는 `StoryRouteInteractable` 요약 마커는 없어야 합니다.
- 유나를 제외한 행동 오브젝트는 중앙 통로를 침범하지 않아야 합니다.
- 8개 방은 서로 다른 바닥 팔레트, 바닥과 벽의 색 대비, 켜진 목표 조명을 가져야 합니다.
- 일시정지 제목과 안내는 한국어이며, 1920×1080에서 폭 460px·높이 120px 이하로 화면 오른쪽에 배치되어야 합니다.
- Esc 1회로 일시정지되고 다시 Esc를 누르면 시간과 이야기 입력이 복원되어야 합니다.

자동 fixture: `Assets/_SmallWorld/Tests/EditMode/Player/Stage15VisualPresentationAcceptanceTests.cs`

## 수동 런타임 QA

1. 신규 게임으로 `04_StoryRoute`에 진입하고 카메라를 움직이지 않은 상태에서 유나의 몸·얼굴·표지와 따뜻한 조명이 즉시 보이는지 확인합니다.
2. 유나에게 가는 직선 동선과 각 방 중앙 이동로를 반복 소품이 막지 않는지 확인합니다.
3. 근접 프롬프트의 대상과 실제 형태가 일치하는지 표본 검사합니다: 인물, 소파, 열쇠, 찻잔, 사진, 시계, 문, 묘비, 모니터, 케이블, 창문, 관리 핵심, 의자, 낡은 컴퓨터.
4. 각 장 진입 직후 바닥·벽·목표 조명의 대비만으로 이전 방과 구분 가능한지 확인합니다.
5. 1280×720과 1920×1080에서 목표 HUD가 잘리지 않고, 일시정지 창이 중앙 조사 대상을 가리지 않는지 확인합니다.
6. Esc → Esc, Tab → Esc, 저장 패널 → Esc 순서에서 커서·플레이어 입력·`Time.timeScale`이 정확히 복원되는지 확인합니다.
7. 프롤로그부터 최종 선택 준비 직전까지 행동을 순서대로 진행하고, 요약 표식만 눌러 장을 건너뛸 수 없는지 확인합니다.

## 범위와 제한

- 이번 기준은 무료 Unity Primitive와 프로젝트 소유 코드로 구성한 최소 가독성 계약입니다.
- 최종 모델·텍스처·애니메이션·사운드 완성도를 의미하지 않습니다.
- 최종 선택과 엔딩 실행은 현재 범위 밖이며 계속 차단되어야 합니다.
- 외부 에셋 사용 없음, 비용 0원, 추가 라이선스 없음.
