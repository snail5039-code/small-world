# 13단계 기억 공간 퍼즐 QA 계획

## 범위

기억 공간의 퍼즐 시작·진행·해결, 탈출 조건, 안전 구역, 하얀 방 복귀, 저장·복원을 검증한다. Stage 1~12의 상호작용·대화·인벤토리·퍼즐·캐릭터·저장 회귀도 함께 확인한다.

## 자동 테스트 기준

- 퍼즐은 초기 상태에서 시작할 수 있고, 반복 입력은 상태를 중복 적용하지 않는다.
- 해결 조건을 만족하면 `Solved`가 1회만 기록되고 탈출이 열린다.
- 해결 전 탈출 요청은 기억 공간에 남아야 하며, 해결 후 탈출은 하얀 방으로 이동해야 한다.
- 안전 구역 안에서는 위험/리셋 이벤트가 진행을 되돌리지 않는다.
- 퍼즐 해결·안전 구역·방문 횟수는 Stage10 저장 데이터에 기록되고 새 인스턴스에서 복원된다.
- 손상되거나 없는 저장 데이터는 기존 복구 규칙을 따르며 게임을 중단시키지 않는다.

## 수동 스모크

1. 하얀 방에서 기억 공간에 입장한다.
2. 퍼즐 오브젝트를 순서대로 상호작용해 해결한다.
3. 해결 전 탈출을 시도하고 차단 메시지를 확인한다.
4. 해결 후 탈출해 하얀 방으로 돌아온다.
5. 저장 후 재실행·불러오기로 해결 상태와 하얀 방 변화를 확인한다.
6. 기존 장면에서 이동, 상호작용, 대화, 사진 퍼즐, 기록, 소녀 캐릭터, 저장 슬롯을 각각 1회 회귀 확인한다.

## 결함 기록 형식

`[Stage13][시나리오] 기대 결과 / 실제 결과 / 로그·재현 절차`

하위 작업은 승인 필요한 명령, 커밋, 푸시를 실행하지 않는다. Unity EditMode, Windows 빌드, 런타임 스모크와 최종 Git 검증은 관리자가 수행한다.
