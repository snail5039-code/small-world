# Stage 15 실제 플레이 도달 가능성·최소 디자인 계약

## 목적

서비스 단위 테스트에서 성공하는 행동이 실제 `04_StoryRoute` 플레이 공간에서도 빠짐없이 실행되는지 검증한다. 장별 공간은 완성 아트 이전에도 플레이어가 서로 다른 장소와 목표로 인식할 수 있는 최소 시각 언어를 갖춰야 한다.

## 필수 도달 가능성 계약

- `OpeningStoryAction`의 모든 값은 활성/비활성 여부와 관계없이 씬의 `Stage15StoryActionInteractable` 하나에 정확히 한 번 직렬화된다.
- 각 액션 상호작용에는 `StoryRouteProgressAdapter`가 연결되어야 한다.
- 장별 행동 순서와 잠김 조건은 `Stage15OpeningStoryService.TryPerform`을 통해서만 판정한다. 잠긴 행동은 진행 플래그를 쓰지 않고 같은 자리에서 즉시 재시도할 수 있어야 한다.
- 선택지는 해당 장의 서비스 계약대로 상호 배타적이어야 하며, 선택하지 않은 분기는 완료 처리되지 않는다.
- 저장 후 복원한 `CurrentChapter`, 행동 플래그, 선택 결과는 같은 상호작용의 중복 실행과 선행 단계 건너뛰기를 계속 차단한다.
- 기존 `StoryRouteInteractable.ConfigureMarker` 기반 Dialogue/Puzzle/Memory 요약 표식은 실제 액션을 실행하지 않고 장 완료를 보고하므로 금지한다. 이동 게이트와 최종 준비 상태 검사처럼 진행 행동을 대체하지 않는 용도만 허용한다.
- 최종장은 `PrepareFinalChoice`까지만 도달 가능하다. 여섯 엔딩 선택 오브젝트와 엔딩 완료/결과 실행은 이번 범위에 존재하지 않아야 한다.

## 최소 디자인 계약

각 방은 다음 네 요소를 모두 갖춘다.

1. 다른 방과 중복되지 않는 바닥 팔레트와 바닥/벽 명도 또는 색상 분리
2. 도착 지점에서 확인 가능한 목표 조명과 입구 표지
3. 해당 장을 한눈에 구분하는 대표 실루엣
4. 조사·퍼즐·기억 대상이 배경 소품과 구분되는 강조 및 충돌하지 않는 이동 표식

대표 실루엣의 최소 기준은 다음과 같다.

| 구간 | 대표 실루엣 |
|---|---|
| 프롤로그 | 빈 인형의 집 |
| 1장 | 비어 있는 네 번째 의자 |
| 2장 | 도착하는 마지막 열차 |
| 3장 | 따뜻한 마을 카페 |
| 4장 | 거울 회의실 |
| 5장 | 작은 장례식장 |
| 6장 | 축소 현실 도시 분지 |
| 최종장 | 얼굴이 박힌 살아 있는 집 벽 |

기본 Primitive 사용 자체는 허용하지만, 크기만 다른 회색 상자로는 대표 실루엣 계약을 충족한 것으로 보지 않는다. 최종 수동 QA에서는 재질 대비, 조명 방향, 소품 배치와 16:9 화면 가독성을 함께 확인한다.

## 현재 기준선에서 예상되는 결과

- 팔레트·조명·입구 표지·이동 표식과 대표 오브젝트 존재 검사는 통과할 수 있다.
- 프롤로그/1장을 제외한 다수 행동은 씬 액션 상호작용이 없어 1:1 도달 가능성 검사가 실패한다.
- 2~6장과 최종장의 Dialogue/Puzzle/Memory 요약 표식은 실제 순서·오답 재시도·선택·저장 계약을 우회하므로 금지 검사에 실패한다.
- 이 실패는 테스트 결함이 아니라 실제 플레이 연결이 아직 서비스 계약에 도달하지 못했다는 승인 게이트다.

## 자동·수동 QA

- EditMode: `Stage15StoryRouteReachabilityContractTests`
- 기존 장별 acceptance fixture: 순서, 오답 재시도, 선택 상호배타, 중간/완료 저장 왕복
- 수동 Windows 빌드: 신규 게임과 장별 저장 데이터로 도착한 뒤 모든 액션을 실제 이동·근접 조사로 수행한다.
- 수동 디자인: 방 입장 3초 이내 장소·대표 실루엣·첫 목표를 구분하고, 다음 조사 대상을 회색 배경과 혼동하지 않는지 확인한다.
