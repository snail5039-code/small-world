# Stage 15 시각 표현 및 화면 사용성 QA

## 목적

사용자 스크린샷에서 확인된 반복 회색 상자, 보이지 않는 첫 목표, 중앙 통로 점유, 낮은 조명 대비와 과도한 영어 일시정지 창이 다시 발생하지 않도록 플레이어 관점의 합격 기준을 고정합니다.

## 자동 계약

- 프롤로그 도착 지점에서 유나까지 거리가 9m 미만이며, 유나는 캡슐 몸체·얼굴·`YUNA` 표지·전용 키 라이트로 구분되어야 합니다.
- 150개 `OpeningStoryAction`은 각각 정확히 하나의 `Stage15StoryActionInteractable`에 연결되어야 합니다.
- 행동 오브젝트 이름은 `Story Action`, 숫자 인덱스 같은 구현 표기를 노출하지 않고 `Character`, `Furniture`, `Doorway`, `Document`, `Clock`, `Terminal` 등 최소 10종 이상의 의미 표현을 사용해야 합니다.
- 기존 `Interaction Gallery Floor`와 장 완료를 우회하는 `StoryRouteInteractable` 요약 마커는 없어야 합니다.
- 유나를 제외한 행동 오브젝트는 중앙 통로를 침범하지 않아야 합니다.
- 8개 방은 서로 다른 바닥 팔레트, 바닥과 벽의 색 대비, 켜진 목표 조명을 가져야 합니다.
- 일시정지 제목과 안내는 한국어이며, 1920×1080에서 폭 460px·높이 120px 이하로 화면 오른쪽에 배치되어야 합니다.
- Esc 1회로 일시정지되고 다시 Esc를 누르면 시간과 이야기 입력이 복원되어야 합니다.
- 모든 월드 표지는 도착 시점 카메라에 정면으로 보이며 거울상으로 뒤집히지 않아야 합니다.
- 유나는 도착점에서 7~9m 떨어진 측면에 배치되어 첫 시야와 이동로를 가리지 않아야 합니다.
- PageUp/PageDown과 물리적 이전/다음 게이트로 해금된 과거 방을 둘러보고 현재 장으로 돌아올 수 있어야 합니다.
- 과거 방 탐색은 `CurrentChapter`, 저장 데이터와 행동 완료 상태를 변경하지 않아야 하며, 현재 장보다 앞서 이동할 수 없습니다.
- 일시정지·기록·저장 패널이 입력을 소유하는 동안 방 이동 입력은 차단되어야 합니다.
- 프롤로그에는 `RealityRoom`으로 돌아가는 명시적인 물리 게이트가 하나만 존재해야 합니다.
- 복귀는 현재 `SaveData` 인스턴스를 장면 세션으로 전달하고 `ActiveSceneId`만 `RealityRoom`으로 바꾸며, `CurrentChapter`, 행동 완료와 관계·선택 상태를 보존해야 합니다.
- 일시정지·기록·저장 패널이 열린 동안 복귀는 거부되고, 이미 장면 전환 중이면 중복 복귀 요청이 시작되지 않아야 합니다.
- 방 이름 표지는 좌우 벽 안쪽 안전 여백을 유지해 16:9 시작 화면에서 글자가 잘리지 않아야 하며, `YUNA` 표지와 프롤로그 설명 표지는 서로 겹치지 않아야 합니다.
- 유나는 머리·몸·좌우 팔·두 눈을 가진 정면 실루엣으로 표현되어 첫 목표가 사람이라는 점을 즉시 알아볼 수 있어야 합니다.

## 수동 런타임 QA

1. 신규 게임으로 `04_StoryRoute`에 진입하고 카메라를 움직이지 않은 상태에서 유나의 몸·얼굴·표지와 따뜻한 조명이 즉시 보이는지 확인합니다.
2. 유나에게 가는 직선 동선과 각 방 중앙 이동로를 반복 소품이 막지 않는지 확인합니다.
3. 근접 프롬프트의 대상과 실제 형태가 일치하는지 표본 검사합니다: 인물, 소파, 열쇠, 찻잔, 사진, 시계, 문, 묘비, 모니터, 케이블, 창문, 관리 핵심, 의자, 낡은 컴퓨터.
4. 각 장 진입 직후 바닥·벽·목표 조명의 대비만으로 이전 방과 구분 가능한지 확인합니다.
5. 1280×720과 1920×1080에서 목표 HUD가 잘리지 않고, 일시정지 창이 중앙 조사 대상을 가리지 않는지 확인합니다.
6. Esc → Esc, Tab → Esc, 저장 패널 → Esc 순서에서 커서·플레이어 입력·`Time.timeScale`이 정확히 복원되는지 확인합니다.
7. 프롤로그부터 최종 선택 준비 직전까지 행동을 순서대로 진행하고, 요약 표식만 눌러 장을 건너뛸 수 없는지 확인합니다.
8. 3장 이상 진행한 저장에서 PageUp 또는 물리적 이전 게이트로 과거 방을 방문한 뒤 PageDown/다음 게이트로 현재 장에 복귀합니다. 방문 전후 저장 파일과 행동 완료 상태가 같은지 확인합니다.
9. 프롤로그 이전과 현재 장 이후 경계에서 이동이 차단되고, 일시정지·기록·저장 화면이 열린 동안 PageUp/PageDown 및 물리 게이트가 작동하지 않는지 확인합니다.
10. 프롤로그 복귀 게이트를 사용해 RealityRoom으로 돌아간 뒤 다시 StoryRoute에 진입하고, 장·행동·관계·선택 상태가 그대로인지 확인합니다.
11. 복귀 게이트 상호작용을 연속 입력해 장면 전환이 한 번만 요청되는지 확인합니다. 일시정지·기록·저장 패널이 열려 있을 때는 요청 자체가 시작되지 않아야 합니다.
12. 1280×720과 1920×1080 시작 화면에서 방 이름 표지 양끝이 벽 밖으로 잘리지 않고, `YUNA`와 설명 텍스트가 겹치지 않는지 확인합니다.
13. 유나를 정면에서 보았을 때 머리·몸·양팔·두 눈이 분리되어 보이며, 어느 눈도 머리 뒤에 숨거나 좌우가 뒤집히지 않는지 확인합니다.

## 좌상단 목표 HUD 계약

- 1280×720과 1920×1080 모두에서 패널은 화면 좌상단 안전 여백 안에 완전히 들어가야 합니다.
- 패널 폭은 화면의 절반보다 작고, 도착 대사가 없을 때 화면 높이의 18% 이하를 사용해야 합니다.
- 공간명은 가장 큰 글자와 강조색, `현재 목표` 표지는 보조색, 실제 목표 문장은 흰색 본문으로 구분합니다.
- 제목·목표·도착 대사는 서로 다른 사각 영역을 사용하고 6px 이상의 세로 간격을 가져야 합니다.
- 도착 대사가 표시될 때만 패널과 대사 영역 높이가 늘어나며, 사라진 뒤 빈 대사 공간이 남지 않아야 합니다.
- 모든 텍스트는 한글 줄바꿈을 허용하고 각 영역 안에서 잘리지 않아야 합니다. 최소 글자 크기는 제목 18px, 목표 15px, 대사 14px입니다.
- 목표 HUD는 오른쪽 위 Pause 패널과 겹치지 않아야 하며, Pause 표시 중에도 현재 공간과 목표를 읽을 수 있어야 합니다.
- HUD 표시 여부와 크기 변경은 PageUp/PageDown·물리 게이트 방 이동, 과거 방 진행 불변, 프롤로그 RealityRoom 복귀와 저장 세션 전달에 영향을 주지 않아야 합니다.

### HUD 수동 확인

1. 1280×720과 1920×1080에서 프롤로그에 진입해 공간명, 현재 목표, 유나 도착 대사의 시각적 우선순위가 제목 → 목표 → 대사 순으로 읽히는지 확인합니다.
2. 8초 뒤 도착 대사가 사라질 때 패널 높이가 줄어들며 목표 문장이 이동·잘림 없이 유지되는지 확인합니다.
3. 가장 긴 장 이름과 목표 문장을 표시해 한글 음절이 패널 경계에서 잘리거나 한 줄로 넘치지 않는지 확인합니다.
4. Esc로 Pause를 열고 좌상단 HUD와 오른쪽 위 Pause 패널 사이에 여백이 유지되는지 확인합니다.
5. HUD가 표시된 상태에서 이전 방 이동·현재 장 복귀·RealityRoom 복귀를 반복하고, 도착 안내만 갱신되며 저장·장·행동 상태는 변하지 않는지 확인합니다.

## 범위와 제한

- 이번 기준은 무료 Unity Primitive와 프로젝트 소유 코드로 구성한 최소 가독성 계약입니다.
- 최종 모델·텍스처·애니메이션·사운드 완성도를 의미하지 않습니다.
- 최종 선택과 엔딩 실행은 현재 범위 밖이며 계속 차단되어야 합니다.
- 외부 에셋 사용 없음, 비용 0원, 추가 라이선스 없음.

## 최신 스크린샷 회귀 계약

이 항목은 기능 테스트가 통과해도 실제 화면이 구 UI·저조도·작은 영어 표지로 보였던 회귀를 차단합니다.

- StoryRoute에는 `Player HUD`와 `Interaction UI`가 각각 하나만 존재하고 구 `Gameplay HUD`가 함께 남지 않아야 합니다.
- 조사 프롬프트는 공통 고대비 테마, 17px 이상, 검은 Outline, 한글 줄바꿈을 사용하며 `Paused`, `Press Esc` 같은 이전 영어 문구를 노출하지 않아야 합니다.
- 프롤로그 이동 가능 영역 3×3 표본의 조도 proxy는 최저 0.25, 평균 0.65 이상이어야 합니다. 유나와 첫 목표 표지는 각각 1.2 이상이어야 합니다.
- 환경광 강도는 0.7 이상이고 환경광 휘도는 0.16 이상이어야 합니다. 천장이 있는 실내이므로 Directional Light만으로 조도 기준을 충족한 것으로 계산하지 않습니다.
- 8개 방 월드 표지는 한국어 공간명을 사용하고 `Chapter`/`Prologue`를 노출하지 않으며 fontSize 64, characterSize 0.09 이상이어야 합니다.
- 각 표지는 정면을 향하고 벽과 3:1 이상 대비되며, 각 방 Arrival 카메라의 8~92% 안전영역 안에 보여야 합니다.
- 1280×720과 1920×1080에서 유나와 첫 목표가 시작 화면 안전영역에 보이고 월드 텍스트끼리 겹치지 않아야 합니다.

수동 확인 시 두 해상도에서 신규 게임 진입 직후 스크린샷을 각각 남기고 다음을 비교합니다.

1. 좌상단 HUD가 어두운 불투명 카드·주황 강조·밝은 본문으로 즉시 구분되는지 확인합니다.
2. 프롤로그 중앙 통로와 양쪽 소품이 회색 덩어리로 사라지지 않고, 유나의 몸·얼굴·팔·눈을 구분할 수 있는지 확인합니다.
3. 공간명과 `유나 · 먼저 대화하기` 표지가 한글로 충분히 크고 벽·천장에 잘리거나 서로 겹치지 않는지 확인합니다.
4. Pause·기록·조사 피드백을 차례로 열어 이전 영어 패널이나 중복 HUD가 다시 나타나지 않는지 확인합니다.
