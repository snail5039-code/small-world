## 현재 검증 결과

- 근접 조사 전용 EditMode: 8/8 통과.
- 전체 EditMode: 284/284 통과.
- 전체 PlayMode: 61/61 통과.
- Windows Development 빌드: 성공.
- 런타임 스모크: `[Stage2Smoke] PASS`.
- 장별 도착 대화·목표·상호작용 피드백과 방별 시각 동선 보강을 완료했다.
- 전체 150개 스토리 행동의 씬 도달 가능성과 2장 이후 요약 표식 우회 차단을 완료했다.
- 8개 방의 반복 상자 갤러리를 제거하고 행동별 의미 소품, 프롤로그 유나 가시성, 중앙 통로, 팔레트·조명 대비를 보강했다.
- StoryRoute Pause UI를 한국어·우상단 반응형 패널로 수정했다.
- 뒤집힌 월드 표지와 유나의 시작 시야 가림을 수정했다.
- PageUp/PageDown과 물리적 이전·다음 방 게이트로 해금된 방을 진행·저장 오염 없이 왕복할 수 있다.
- 프롤로그 전용 게이트와 Home 키로 스토리 상태를 보존하며 RealityRoom에 복귀할 수 있다.
- 프롤로그 공간명 잘림과 유나 표지 중첩을 수정하고 유나에 머리·팔·눈 방향을 추가했다.
- 1~15단계 공통 UI 테마, 안전영역, 한글 프롬프트, 모달 입력 소유권과 화면 회귀 계약을 추가했다.
- StoryRoute 목표·Pause·기록을 compact 카드로 통일하고 프롤로그 조도·한글 월드 표지·대비판 생성 규칙을 보강했다. `00_Boot`~`04_StoryRoute` 씬 재생성·UI 기준 적용과 새 Windows 빌드 검증까지 완료했다.
- 8개 방에 장별 문틀·가구·생활 소품·환경 실루엣을 추가하고 과도한 발광 프레임·바닥 표식·디버그 비콘을 축소했다. 150개 조사와 15개 이동 게이트의 물리 도달성 회귀도 검증했다.
- 스토리방 전환 중 InteractionPrompt 피드백 Coroutine이 먼저 무효화될 때 발생하던 `ArgumentNullException`을 제거하고 실제 프레임·StoryRoute 로드 PlayMode 회귀를 추가했다.
- Boot부터 StoryRoute까지 목표·조사·대화·기록·저장·설정·로딩·Pause UI를 공통 체계로 통일하고, 720p/1080p 한글·최소 글자 크기·긴 문구·44px 버튼·모달 레이어 계약을 실제 씬에 적용했다.
- 다음 구현 범위는 조사 스테이션을 장별 실제 퍼즐 조작과 기억 공간 연출로 고도화하는 것이다.

완료 기준: 새 게임부터 최종 선택 직전까지 막힘 없이 진행할 수 있어야 한다.
