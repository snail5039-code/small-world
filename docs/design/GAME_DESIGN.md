## 핵심 요약

`둘만의 작은 세계: 아무것도 남지 않은 하얀 방`은 Windows PC용 1인칭 심리 공포 어드벤처·탈출 퍼즐입니다. 화면 속 소녀와 관계를 쌓고 집을 완성하는 친밀한 경험이 기억·정체성·선택을 다루는 공포로 전환됩니다. 전투 없이 조사, 대화와 선택, 모형 집 공간 조작, 기억 퍼즐, 추격, 다중 엔딩을 결합합니다.
