# 15단계 장별 대화·플레이 동선 발견성 QA 의미 계약

## 목적과 경계

프롤로그부터 최종 선택 직전까지 플레이어가 외부 설명 없이 각 장의 `도착 → 안내 대화 → 조사 → 퍼즐 → 귀환` 흐름을 발견하고, 진행 불가 상태에 빠지지 않는지 검증한다. 이 문서는 플레이어가 관찰할 수 있는 의미만 고정한다. 구현 타입, 메서드, 오브젝트, 저장 키, fixture 이름은 구현 담당자가 공개한 계약을 받은 뒤 별도 자동 테스트에 연결한다.

실제 최종 선택 실행과 엔딩 결과는 검증하거나 호출하지 않는다. 런타임, 씬, 생성기는 QA 수정 범위 밖이다. 외부 에셋은 사용하지 않는다.

## 공통 발견성 계약

각 장은 다음 조건을 모두 만족해야 한다.

1. 도착 직후 공간명이 한 번 이상 식별 가능하고, 현재 목표가 행동 가능한 문장으로 보인다.
2. 안내 대화가 끝나면 첫 필수 조사 대상 또는 그 방향을 알 수 있다.
3. 상호작용 가능 거리에서는 근접 프롬프트가 나타나고, 거리 밖·비활성 대상에는 오해를 부르는 프롬프트가 남지 않는다.
4. 순서 밖 행동, 오답, 잠긴 출구에는 서로 구분되는 사유가 표시되고 같은 단계에서 재시도할 수 있다.
5. 필수 행동 하나가 끝날 때마다 현재 목표 또는 다음 마커가 갱신된다. 이미 끝난 대상으로 되돌아가도록 안내하지 않는다.
6. 조사와 퍼즐 완료 뒤 귀환 지점이 발견 가능하며, 귀환 뒤 다음 장 또는 다음 필수 대화가 명확하다.
7. 관계 상태에 따라 대사가 달라도 필수 조사, 퍼즐, 귀환 경로는 숨거나 잠기지 않는다.
8. 현재 장 밖의 방 골격, 차폐 밖 공간, 다음 장의 필수 오브젝트는 보이지 않거나 접근할 수 없다.

## 장별 종단 매트릭스

| 구간 | 도착·안내 | 조사·퍼즐 | 귀환·다음 안내 |
|---|---|---|---|
| 프롤로그 | 현실 방과 게임 속 거실의 공간 전환, 첫 만남, 현재 목표를 식별한다. | 필수 조사와 첫 가구/이상 현상 흐름이 순차 안내되며 첫 기억 문을 조기에 통과할 수 없다. | 첫 기억 문으로 향할 이유와 잠김 사유가 보이고, 완료 뒤 1장만 이어진다. |
| 1장 `네 번째 자리` | 기억 공간 도착과 가족 식사 상황을 이해한다. | 네 시각, 네 사람분 식사, 사진 순서, 존재하지 않는 방, 이름표 단계가 목표·오답·다음 마커로 이어진다. | 추격 또는 탈출 뒤 집 귀환을 찾을 수 있고 2장 안내가 열린다. |
| 2장 `마지막 승강장` | 승강장과 첫 조사 대상을 식별한다. | 노선도, 분실물, 역재생 방송, 목적지, 안전 구역이 순서대로 안내되고 오답은 진행시키지 않는다. | 안전 구역 뒤 귀환 지점과 3장 안내를 찾을 수 있다. |
| 3장 `완벽한 하루` | 카페 상황과 첫 대화/메뉴 조사를 식별한다. | 주문, 선택지 밖 대답, 석양, 사진 선택이 순서대로 안내되고 잠김·오답 사유가 구분된다. | 사진 선택 뒤 귀환 지점과 4장 안내를 찾을 수 있다. |
| 4장 `얼굴 없는 사무실` | 사무실 상황과 권한 조사 시작점을 식별한다. | 인격 권한, 삭제 로그, 거울 회의실, 기록 선택이 목표·오답·다음 마커로 이어진다. | 추격 또는 탈출 뒤 귀환 지점과 5장 안내를 찾을 수 있다. |
| 5장 `장례식 없는 묘지` | 묘지 상황과 첫 기록 조사를 식별한다. | 사망진단서, 방명록, 빈 묘비, 이름 선택이 순차 안내되고 미완료 잠김 사유가 보인다. | 선택 뒤 귀환 지점과 6장 안내를 찾을 수 있다. |
| 6장 `창문 안의 도시` | 도시와 개발자 방으로 이어지는 첫 목표를 식별한다. | 개발자 방, 모니터 순서, 파형, 현실 연결이 순차 안내되고 추격 중에도 안전한 다음 목표가 식별된다. | 귀환 뒤 최종장 입구 안내를 찾을 수 있다. |
| 최종장 선택 직전 | 살아 있는 집, 관리 핵심, 현실 연결, 하얀 방의 순서를 안내받는다. | 조건 미달은 누락 사유와 다음 행동을 표시하고, 충족 시 하얀 방까지 이동한다. | 최종 선택 UI나 결과를 실행하지 않은 준비 상태에서 멈춘다. |

## 입력·저장·복원 계약

- 이동·근접 상호작용 중 `Tab` 기록을 열고 닫으면 기존 목표와 프롬프트가 복원되고 중복 진행이 발생하지 않는다.
- `Esc` 일시정지를 열고 닫으면 시간, 커서, 이동, 상호작용 소유권이 정상 복원된다.
- 저장 UI가 입력을 소유하는 동안 `Tab`과 `Esc`가 기록·일시정지 상태를 동시에 열거나 닫지 않는다.
- 각 장의 도착, 안내 대화 후, 조사/퍼즐 중간, 귀환 직전에서 저장·복원하면 `CurrentChapter`에 해당하는 안전한 도착 지점과 아직 필요한 목표가 복원된다.
- 잘못된 장 값은 정해진 안전 폴백으로 복원되며 다른 방 골격이나 최종 선택 상태를 노출하지 않는다.
- 복원 후 공간명, 현재 목표, 마커, 프롬프트, 잠김 사유가 저장된 진행 상태와 모순되지 않고 일회 대화·보상을 중복 실행하지 않는다.

## 시각 안내 계약

- 현재 장의 이동 가능 영역은 바닥·벽·천장·입구 차폐로 다른 방 골격과 구분된다.
- 필수 경로, 상호작용 대상, 위험/잠김 상태는 색 하나에만 의존하지 않고 밝기, 형태, 문구 또는 마커 중 하나 이상의 보조 신호를 갖는다.
- 공간 조명과 강조는 목표 대상의 프롬프트·문구를 읽을 수 있게 하며, 장식 강조가 필수 대상보다 강해 잘못된 경로를 유도하지 않는다.
- 카메라 배경과 방 경계에서 회색 골격, 미완성 공간, 다음 방의 조명이나 마커가 노출되지 않는다.

## 확정된 구현 계약과 자동화 연결

구현 계약은 대화·안내 커밋 `e83e247`과 환경 커밋 `d842489`을 정본으로 삼는다.

- `StoryRouteGuidance.Location`, `ArrivalObjective`, `ArrivalDialogue`, `NextObjective`: 장별 공간명, 도착 목표, 관계별 안내, 성공/잠김 뒤 다음 마커, 최종 선택 미실행 문구.
- `StoryRouteController.CurrentLocation`, `CurrentObjective`, `UpdateGuidance`, `UpdateObjective`: 현재 화면 안내의 관찰·갱신.
- `StoryRouteController.RestoreToNodeOrPrologue`: 요청 장의 Arrival 복원과 잘못된 값의 프롤로그 폴백.
- `StoryRouteProgressAdapter.CurrentChapter`, `CurrentChapterNodeIndex`, `PresentArrival`, `PerformOpeningAction`: 저장 진행과 현재 장, 도착 안내, 행동 결과 및 잠김/완료 피드백 연결.
- `Stage15StoryActionInteractable.ConfigureAction`: `조사:` 근접 프롬프트와 실제 이야기 행동 연결.
- `StoryRouteController.HandleTabPressed`, `HandleEscapePressed`, `IsRuntimeOverlayOpen`, `IsRuntimePaused`: 기록·일시정지·저장 UI 입력 소유권 관찰.
- 씬의 `Route Room {0..7} Entrance Sign`, `Objective Light`, `Dialogue Highlight`, `Puzzle Highlight`, `Memory Highlight`, `Path {1..3}-{1..3}`: 8개 방의 공간 안내, 목표 강조, 비차단 경로 계약. Path collider는 모두 비활성이고 방별 바닥 팔레트는 고유하며 바닥/벽 재질은 구분된다.

자동 공통 fixture `Stage15StoryRouteDiscoverabilityContractTests`가 공간명·목표·관계 분기·성공/잠김 힌트·최종 선택 미실행, `CurrentChapter` Arrival 복원/폴백, 8방 표지·조명·강조·경로·팔레트를 검증한다. `Tab`/`Esc`/저장 입력은 기존 `Stage15PrologueChapter1SceneTests`, 세부 안내 단위 계약은 기존 `StoryRouteGuidanceTests`와 함께 실행한다. 실제 가독성과 플레이어 발견성은 Windows 빌드 수동 QA로 유지한다.

## 실패 판정

- **Blocker**: 필수 목표를 찾을 수 없거나 진행이 영구 잠김, 잘못된 방/최종 선택 실행, 저장 복원 뒤 진행 불가.
- **Critical**: 장 순서 우회, 다른 방 골격 노출로 경로 이탈, 입력 소유권 충돌로 진행/저장 손상.
- **Major**: 목표·마커·프롬프트·잠김 사유가 서로 모순되거나 관계 분기가 필수 진행을 숨김.
- **Minor**: 진행은 가능하지만 색·조명·강조 또는 문구가 불명확해 반복 탐색이 필요함.

## 외부 에셋과 라이선스

추가하거나 사용한 외부 에셋 없음. 프로젝트 소유 문서와 정본 스토리만 참조한다.
