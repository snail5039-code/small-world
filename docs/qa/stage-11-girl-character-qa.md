# Stage 11 소녀 캐릭터 QA

## 범위와 완료 게이트

- 대상은 임시/최종 소녀 모델, 기본 애니메이션, 시선, 표정, 방 안 이동, 플레이어 반응, 관계별 행동, 대화 연결, 저장 및 사망 기억 반응이다.
- 완료 기준은 **플레이어의 현재 행동과 저장에서 복원한 상태가 동일한 규칙으로 소녀의 관찰 가능한 반응을 바꾸는 것**이다.
- QA는 기능 코드나 씬 생성 결과를 대신 구현하지 않는다. 구현 계약이 확정되면 공개 API 중심의 EditMode 테스트와 실제 씬의 PlayMode/런타임 점검으로 검증한다.
- 각 자동 테스트는 시간, 프레임률, 로캘 및 테스트 실행 순서에 의존하지 않아야 한다.
- 외부 모델·애니메이션·텍스처·음원은 통합 전에 `docs/management/THIRD_PARTY_ASSETS.md`에 출처, 버전, 무료 상업 이용, 수정·재배포·표기 조건과 증빙이 등록되어야 한다.

## 씬 및 에셋 정적 점검

1. 캐릭터 루트와 시각 모델의 소유 경로가 `_SmallWorld` 아래인지 확인한다.
2. 모델, 애니메이션 클립, 텍스처, 셰이더, 음성이 새로 추가되었는지 `git diff --name-status`로 분류한다.
3. 외부 파일이면 등록부 항목과 실제 파일의 제작자·원본 URL·버전·라이선스 증빙·SHA-256이 일치하는지 확인한다.
4. 무료 다운로드라는 이유만으로 상업 이용 가능으로 판정하지 않는다. 상업 이용, 수정, 빌드 포함 재배포 조건이 명시되어야 한다.
5. 씬 YAML에서 Missing Script, 빈 필수 참조, 중복 GUID를 정적 검사하고 Unity에서 다시 열어 Console을 확인한다.
