## 1단계 — 프로젝트 기반 확정

- [ ] Unity 프로젝트 정상 실행 확인
- [ ] 프로젝트 전용 폴더 구조 생성
- [ ] Git 저장소와 Unity `.gitignore` 구성
- [ ] URP 설정 확인
- [ ] Input System 설정
- [ ] DX11 우선 설정
- [ ] Windows IL2CPP 빌드 설정
- [ ] 게임 제목, 회사명, 버전 설정
- [ ] 개발·테스트·출시 빌드 설정 분리
- [ ] 무료 에셋 라이선스 기록 문서 생성
- [ ] 기본 Windows 빌드 실행 테스트

완료 기준: 빈 장면을 Windows 실행 파일로 빌드하고 정상 실행할 수 있어야 한다.
