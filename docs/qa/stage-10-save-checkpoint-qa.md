# Stage 10 저장·체크포인트 QA

## 범위와 원칙

- 대상은 Stage 10 저장·복원과 Stage 6~9 회귀다.
- 기능 코드와 프로젝트 설정은 수정하지 않는다.
- 저장 테스트는 매 사례마다 격리된 임시 저장 디렉터리에서 시작하고 종료 후 제거한다.
- 설정 데이터는 진행 저장과 별도 파일/수명 주기를 가져야 한다.
- 파일 변경 테스트는 게임 프로세스가 종료된 상태에서 수행한다.

## 런타임 스모크

1. 빌드에서 새 게임을 시작하고 퍼즐 일부 진행, 관계 변화, 기록 획득, 설정 변경을 만든다.
2. 하얀 의자에서 체크포인트를 만들고 수동 슬롯 1에 저장한다.
3. 상태를 더 변경해 자동 저장을 발생시키고 게임을 정상 종료한다.
4. 프로세스를 다시 실행해 이어하기 결과가 최신 자동 저장과 일치하는지 확인한다.
5. 체크포인트 복원과 슬롯 1 불러오기를 각각 실행해 서로 다른 시점이 정확히 복원되는지 확인한다.
6. 진행 초기화 후 새 게임을 시작해 진행 데이터는 초기화되고 설정은 유지되는지 확인한다.

## Stage 6~9 회귀

- Stage 6: HUD 상태 전환, 설정 바인딩, 접근성 값 왕복, 장면 UI 통합 테스트가 통과한다.
- Stage 7: 대사 진행/선택/조건/스킵과 대사 UI 장면 통합 테스트가 통과한다. 복원 시 선택 효과를 두 번 적용하지 않는다.
- Stage 8: 인벤토리 추가·중복 방지·정렬·필터와 기록 UI 장면 통합 테스트가 통과한다. 복원된 획득 순서가 유지된다.
- Stage 9: 퍼즐 스냅샷 왕복·손상 격리·새 게임 초기화·사진 퍼즐 장면 통합 테스트가 통과한다. 구형 `smallworld.stage9.photo-puzzle.v1` 데이터의 처리 정책이 명시되어야 한다.

## 수동 실패 재현 보고 형식

각 실패는 다음 항목을 기록한다.

1. 테스트 ID, 실행 환경, 기준 커밋
2. 격리 저장 디렉터리의 초기 파일 목록과 각 파일 해시
3. 재현 단계와 실패 주입 지점
4. 기대 결과와 실제 결과
5. 종료 후 파일 목록, 각 파일 해시, 격리/임시 파일 내용
6. Console/Player 로그의 첫 오류와 전체 스택 추적
7. 수정 대상 계약과 재검증할 테스트 ID

## 2026-08-10 통합 감사 결과

### 통과한 정적 계약

- 반복 손상 복구는 `.repair.tmp`에서 주 파일만 교체하며 정상 `.bak`를 보존한다.
- 자동 저장은 두 슬롯을 교대하고 최신 시각을 선택한다.
- 수동 저장 슬롯 인덱스는 0~2로 제한된다.
- 새 게임은 Stage 10 진행 파일과 Stage 9 구형 `PlayerPrefs` 키를 장면 전환 전에 제거한다.
- Stage 9 퍼즐의 상시 `PlayerPrefs` 저장은 제거됐고 구형 데이터는 Stage 10으로 1회 마이그레이션된다.

### 검토 중 발견 후 수정된 항목

#### S10-05-R 관계 상태의 완전 교체 실패

1. 현재 관계 변수 `a=5`, `b=9`를 만든다.
2. `a=1`만 포함한 이전 저장을 불러온다.
3. 실제 결과: `a=1`로 바뀌지만 저장에 없는 `b=9`가 남는다.
4. 기대 결과: 저장 스냅샷과 정확히 같아야 하므로 `b`는 제거되거나 기본값 0이어야 한다.
5. 수정 요청: `DialogueState`에 전체 교체용 공개 계약을 추가하고, 복원 시작 시 기존 변수를 지운 뒤 저장된 관계 값을 적용한다.

수정 확인: `DialogueState.Clear()`와 복원 전 초기화가 추가됐고, 잔류 관계 값 회귀 테스트가 추가됐다.

#### S10-05-P 쉼표 소수점 로캘에서 위치 복원 실패

1. 현재 문화권을 `fr-FR` 등 소수점 구분자가 쉼표인 문화권으로 설정한다.
2. 플레이어 위치 `(1.5, 2.25, 3.75)`를 저장하고 다시 불러온다.
3. 실제 결과: 저장 문자열이 `1,5,2,25,3,75`가 되어 세 요소 파싱에 실패하고 위치가 `(0,0,0)`으로 복원된다.
4. 수정 요청: 위치/회전의 `ToString("R", CultureInfo.InvariantCulture)`와 `float.TryParse(..., NumberStyles.Float, CultureInfo.InvariantCulture, ...)`를 사용한다.

수정 확인: 캡처와 복원 양쪽 모두 `InvariantCulture`를 사용하도록 변경됐다.

### 남은 실패 및 정확한 수정 요청

#### S10-SCENE RealityRoom 미통합

1. `02_RealityRoom.unity`에서 `Stage 10 Save Integration`, `White Save Chair`, `Reality Entry Auto Save Trigger`, `Manual Save Slots`를 검색한다.
2. 실제 결과: 해당 오브젝트와 컴포넌트가 없다.
3. 수정 요청: `Stage10SaveIntegrationGenerator.GenerateAndValidate`를 적용해 씬을 저장한 뒤, 생성기 재실행 멱등성과 씬 통합 테스트를 확인한다.
