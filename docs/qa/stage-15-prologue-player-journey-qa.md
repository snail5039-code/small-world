# Stage 15 프롤로그 플레이어 여정 QA

## 승인 기준

프롤로그 첫 방은 다음 다섯 질문에 모두 “예”여야 한다.

1. 첫 화면이 회색 테스트 공간이 아니라 문틀·벽·소파·테이블·책장·조명이 있는 실제 방처럼 읽히는가?
2. HUD를 읽지 않아도 유나가 인물로 보이고, 문 개구를 지나 7~9m 안에서 접근·조사할 수 있는가?
3. 유나 조사 성공 뒤 “소파”라는 다음 행동과 실제 소파 조사 오브젝트를 연결할 수 있는가?
4. 마지막 프롤로그 행동 뒤 초기 목표로 되돌아가지 않고 다음 방 문을 명시하는가?
5. 중앙의 보이는 실내문을 CharacterController가 실제 통과해 그 뒤의 `Route Room 0 Next Room Gate`에 닿을 수 있는가?

`Stage15ProloguePlayerJourneyAcceptanceTests`는 두 해상도 첫 화면의 방 실루엣 5개 이상, 디버그 안내물 0개, 유나 시야·거리·차폐, 첫→다음 행동 거리와 프롬프트, 종료 행동의 문 안내, 내부 문 폭·충돌·게이트 위치를 검증한다.

## 1280×720 / 1920×1080 수동 체크

| 순서 | 플레이 | 합격 기준 |
|---|---|---|
| 새 진입 | 마우스를 움직이지 않고 3초 관찰 | 문틀과 생활 가구가 먼저 읽히고 유나가 화면 안에 있음. 월드 글자·발광 프레임·HUD가 방의 절반을 가리지 않음 |
| 첫 접근 | 유나에게 걸어가며 정면·측면 조준 | 벽이나 가구에 막히지 않고 2.75m 안에서 한글 `[E]` 프롬프트가 안정적으로 유지됨 |
| 첫 행동 | 유나 조사 후 피드백과 HUD 확인 | 성공 결과와 “소파”가 동시에 읽히고 4초 안에 실제 소파 방향을 판단할 수 있음 |
| 다음 행동 | 소파→열쇠·찻잔·사진 조각 순으로 이동 | 오순서는 잠김 이유와 직전 행동을, 정순은 다음 물건을 알려 주며 진행이 멈추지 않음 |
| 프롤로그 종료 | 예약 메일→기억 문→질문/닫기 선택 | 다음 방 문이 목표로 표시되고 초기 “유나와 대화” 문구로 되돌아가지 않음 |
| 문 통과 | 중앙 실내문을 정면으로 통과한 뒤 다음 방 게이트 E | 보이는 개구와 실제 충돌이 일치하고 가구에 막히지 않으며 1장 Arrival로 이동함 |
| UI 회귀 | 각 단계에서 Tab, Esc, 저장 열기/닫기 | 목표·Prompt·기록·Pause·저장이 겹치지 않고 동일 키가 두 UI를 동시에 실행하지 않음 |
| 로그 | 1장 진입 후 종료 | Player.log exception, NullReference, coroutine 오류 0건 |

## 기준 HEAD 감사 결과

- 프롤로그 종료 행동 `QuestionMemoryDoor`, `LeaveMemoryDoorClosed`는 현재 `NextObjective` 전용 분기가 없어 초기 도착 목표로 폴백할 가능성이 있다.
- 중앙 실내문 바로 앞의 `Prologue Media Console`은 Collider가 있는 폭 3.4m 가구이며 4.5m 문 개구 중앙을 차지한다. 실제 CharacterController 통과 폭을 막는지 자동 계약과 Windows 플레이에서 확인해야 한다.
- 나머지 최종 캐릭터 모델·텍스처·사운드·애니메이션과 실제 퍼즐 조작 연출은 아직 블록아웃 범위다.

외부 에셋과 추가 라이선스는 사용하지 않는다.
